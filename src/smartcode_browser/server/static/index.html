开始浏览

① 选择上方项目 → ② 搜索（定义/调用切换；in:nemu/ main 限定路径）→ ③ 点击函数体内蓝色调用向右展开定义。

已有调用树时，搜索点击会新开根节点与现有树并列；Shift+点击挂到当前面板；Ctrl+点击替换整棵树。

右侧函数地图以 父 → 子 扁平列出调用链，点击跳到对应面板。

浏览状态会自动保存，刷新或重启后会恢复；也可点顶栏「保存到标签」把当前代码树存成书签。

同一函数已在树中时会复用面板；按住 Shift 点击可强制新开。

拖动标题栏可移动面板，其余子面板会自动避让重排；双击标题栏恢复自动布局。

代码区任意位置右键 → AI 分析（无需先选中文本），或在面板标题栏点 ✦；分析记录按函数保存。
