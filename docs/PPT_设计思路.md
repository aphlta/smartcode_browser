# SmartCode Browser · 项目介绍（PPT 讲稿）

> 按「一节 = 一页」做成幻灯片即可。侧重**介绍是什么、能干什么**，不讲实现细节。  
> 本项目在 Cursor 中用 AI 辅助迭代完成。

---

## 第 1 页 · 这是什么？

**SmartCode Browser — 级联式代码浏览器**

- 在浏览器里读代码的 **Web 小工具**
- 点函数里的**蓝色调用**，在**右侧**展开被调函数的定义，一层层跟下去，形成**横向调用树**
- **语言无关**：C/C++、Python、Java、Scala/Chisel 等（通过配置切换项目与语言）
- **工具与源码分离**：浏览器只装一份；Linux 内核、Chipyard 等代码库在服务器上单独 clone，用配置文件挂上即可

**一句话**：专门用来**沿调用链读大库**，不是 IDE，不负责改代码、编译、调试。

---

## 第 2 页 · 解决什么麻烦？

读 **Linux 内核**、**芯片/Chisel** 这类大工程时，常见情况是：

- 函数散落在很多文件里，IDE 里跳来跳去，**容易丢上下文**
- 只想**跟一条调用路径**，不想把整个工程导入 IDE
- 代码在**远程服务器**上，本机 IDE 够不着，但希望能像网页一样打开就看

**我们想做的事**

> 从某个入口函数出发，**顺着「谁调谁」一路往下看**，路径清楚、还能保存下来给别人看。

---

## 第 3 页 · 怎么用？（核心体验）

```
[ 函数 A ]  ──点蓝色调用──▶  [ 函数 B ]  ──再点──▶  [ 函数 C ]  …
   左侧保留                     在右侧长出新面板，不盖住左边
```

**常用操作（记这四条就够）**

| 操作 | 效果 |
|------|------|
| 点蓝色调用 | 打开被调函数，级联展开 |
| 点变量名 | 跳到声明（全局/字段会开新面板） |
| 搜索符号 | 从任意函数名进入，再开始跟链 |
| 保存标签 | 把当前这条探索路径命名，下次一键恢复 |

刷新页面也会**自动恢复**上次的阅读树，适合中途被打断再继续。

---

## 第 4 页 · 还能做什么？

- **查找用法**：看谁在用这个函数（快捷键或右键）
- **多项目切换**：顶栏下拉，今天看内核 cpuidle，明天看 Chipyard，不用重装工具
- **大库友好**：可只索引子目录（例如只索引 `drivers/cpuidle` 相关路径），启动更快
- **可选 AI 问答**：在当前函数面板里提问（依赖 Cursor CLI 登录，不必单独配 API Key）—— 辅助理解，**不替代**点调用跟链

---

## 第 5 页 · 适合谁、典型场景

| 谁 | 用来干什么 |
|----|------------|
| 内核 / 驱动工程师 | 从 cpuidle、sched 等入口跟 governor → driver → 平台实现 |
| 芯片 / 验证 | 在 Scala/Chisel 生成逻辑里追模块与连接 |
| 评审 / 牵头人 | 把调查路径存成标签，会上直接打开同一条调用树 |
| 远程协作 | 内网或 SSH 隧道打开浏览器，读服务器上的只读源码 |

**和 IDE 的分工**：IDE 负责**改代码**；这个工具负责**跟调用链、讲清楚路径**。

---

## 第 6 页 · 和 AI 的关系（简要）

**怎么来的**

- 从真实场景（例如读内核 cpuidle 调用链）出发提需求
- 在 **Cursor** 里用 Agent 结对做出界面、索引、多语言支持
- 人负责定范围、验场景；AI 负责快速实现与迭代

**工具里的 AI（可选）**

- 对**当前正在看的函数**做解释型提问
- 和「点蓝色调用跟链」是两套能力：一个**跟路径**，一个**问含义**

---

## 第 7 页 · 总结

| 关键词 | 含义 |
|--------|------|
| **级联** | 调用关系在屏幕上长成一棵树，一目了然 |
| **无关** | 换语言、换项目主要靠配置，不换工具 |
| **可续** | 路径可恢复、可存标签，方便协作与汇报 |

**收尾一句**

> SmartCode Browser：把读大库变成「沿调用树散步」—— 轻量、Web、专为追调用链而做；由 AI 辅助快速落地到真实工程场景。
